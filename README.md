# Characterizing Sunlit Days

Multi-sensor study of solar irradiance patterns and their environmental
drivers in Johnstown. Mentorship Fund project, University of Pittsburgh
at Johnstown, Fall 2026.

## Layout

- `docs/` - packet format and other specifications
- `node/` - Arduino sketch for the outdoor sensor node
- `receiver/` - Arduino sketch for the LoRa receiver
- `basestation/` - ingest service, API, and web app
- `data/reference/` - historical weather data for comparison

## Where things live

Code and specifications are in this repository. Spreadsheets, documents
and slides are on the team shared drive.

## Status

In progress. Hardware not yet ordered.
